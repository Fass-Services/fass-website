## Usage

### Adding New Research

1. Create markdown files in the appropriate folder
2. Use consistent formatting (see existing files)
3. Include data sources and dates
4. Update this README when adding new products

### Updating Value Props

Value propositions should be updated quarterly or when:
- Market conditions change significantly
- Pricing model changes
- New competitive threats emerge
- Product pivots occur

## Data Sources

Research in this workspace draws from:
- Industry reports (PS Market Research, MarketsandMarkets, Technavio)
- Competitor analysis (public pricing, feature comparisons)
- Internal product documentation
- Web research (Context7, Exa AI)

All data should include source attribution and dates for freshness tracking.
