# AppSumo Launch Plan — Tax Companion & Autografik

← [Back to Strategy Index](../README.md)

**Goal:** Launch both products on AppSumo to generate initial revenue, user base, and social proof.

---

## Revenue Split Reality

| Deal Type | AppSumo Takes | You Keep |
|-----------|---------------|----------|
| Standard Marketplace | 50-70% | 30-50% |
| AppSumo Select | ~50% | ~50% |
| Negotiated (post-traction) | 30-50% | 50-70% |

**Assume 50% split for planning.** First-time sellers rarely negotiate better.

---

## Phase 1: Pre-Launch Preparation (4-6 weeks before)

### Product Readiness

| Requirement | Tax Companion | Autografik |
|-------------|---------------|------------|
| Core features complete | ✅ Pro tier working | ✅ Pro tier working |
| Onboarding flow | Needs polish | Needs polish |
| Help docs / FAQ | Create | Create |
| Demo video (2-3 min) | Required | Required |
| Landing page | Update for LTD | Update for LTD |

### AppSumo Requirements

- [ ] **Partner application** — Apply at [sell.appsumo.com](https://sell.appsumo.com)
- [ ] **Product demo video** — 2-3 min screencast showing core value
- [ ] **Product screenshots** — 5-8 high-quality images
- [ ] **Deal copy** — Headline, description, feature bullets
- [ ] **Redemption flow** — How users claim their license (email → license key)
- [ ] **Support plan** — Dedicated email or helpdesk for AppSumo surge

### Pricing Strategy

| Product | Direct Price | AppSumo LTD Price | You Keep (50%) |
|---------|--------------|-------------------|----------------|
| Tax Companion | $49/year | $59 lifetime | ~$29.50 |
| Autografik | $29 lifetime | $39 lifetime | ~$19.50 |

**Why price higher on AppSumo?** LTD buyers expect "deals" — a $59 LTD vs $49/year feels like a win. You also offset the platform cut.

## Phase 2: Application & Approval (2-4 weeks)

### Week 1-2: Submit Application

1. Go to [sell.appsumo.com](https://sell.appsumo.com)
2. Complete partner profile
3. Submit product for review with:
   - Product name & URL
   - Demo video link
   - Pricing tier request
   - Expected deal structure

### Week 3-4: AppSumo Review

- AppSumo team evaluates product fit
- May request changes to pricing or features
- Negotiate split if possible (unlikely for first deal)
- Schedule launch date

### Launch Order Recommendation

| Order | Product | Why |
|-------|---------|-----|
| 1st | **Autografik** | Simpler product, lower support burden, test the waters |
| 2nd | **Tax Companion** | Launch Jan-Feb (tax season), higher complexity |

---

## Phase 3: Launch Week (7 days)

### Day 1-2: Launch

- [ ] AppSumo sends email blast to 1M+ subscribers
- [ ] Monitor sales dashboard hourly
- [ ] Respond to questions in AppSumo comments within 2 hours
- [ ] Track redemption rate (sales → activated users)

### Day 3-5: Engagement

- [ ] Reply to every comment (AppSumo ranks by engagement)
- [ ] Address feature requests publicly ("Great idea, added to roadmap!")
- [ ] Fix any critical bugs immediately
- [ ] Post updates if you ship improvements mid-launch

### Day 6-7: Push for Reviews

- [ ] Email redeemed users asking for AppSumo reviews
- [ ] Offer bonus (template, feature) for 5-star reviews
- [ ] Target: 50+ reviews by end of launch week

### Support Surge Plan

| Volume | Response |
|--------|----------|
| 0-50 sales | Handle personally |
| 50-200 sales | Canned responses + personal follow-up |
| 200+ sales | Consider temporary support help |

---

## Phase 4: Post-Launch (30-60 days)

### Metrics to Track

| Metric | Target | Action if Below |
|--------|--------|-----------------|
| Redemption rate | >80% | Simplify redemption flow |
| Review score | >4.5 stars | Address complaints, improve UX |
| Support tickets | <10% of sales | Improve docs, add FAQ |
| Refund rate | <5% | Investigate common complaints |

### Convert LTD Buyers to Advocates

- [ ] Email sequence: Day 1, Day 7, Day 30
- [ ] Ask for referrals to non-AppSumo users
- [ ] Invite to beta test new features
- [ ] Request testimonials for direct sales page

### Lessons → Direct Sales

Use AppSumo feedback to improve:
- Messaging (what resonated?)
- Features (what did people ask for?)
- Objections (what almost stopped them?)

Apply learnings to direct sales funnel.
